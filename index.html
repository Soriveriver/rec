  1. console.groq.com에 구글 계정으로 로그인
  2. Create API Key를 눌러 만든 gsk_… 키 복사
  3. 아래에 붙여넣고 저장

키는 이 폰 안에만 저장되고, 녹음을 보낼 때 Groq에만 전달됩니다.

음성 메모→녹음 선택→공유→파일에 저장→위 버튼
